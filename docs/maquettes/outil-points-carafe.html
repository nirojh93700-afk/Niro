Placez les points de gravure — Carafe

Choisis ● Texte / Nom ou ● Date, puis tape (un petit coup) l'endroit du dessin où ça sera gravé. Tu peux faire défiler normalement — un point ne se pose que sur un vrai tap. Touche un point pour le retirer. Un point bleu suffit s'il n'y a pas de date.

34 modèles carafe. Place le point là où le prénom (et la date) apparaissent sur l'exemple.
