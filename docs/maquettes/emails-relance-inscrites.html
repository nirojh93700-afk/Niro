  • Le code GRAVUREOFFERTE doit exister pour de vrai. Le plus simple et le plus sûr : un code de −3 € (le montant du supplément gravure), créé dans Promotions, et limité aux bijoux, aux cristaux et aux cadeaux gravés. Sinon la cliente aurait un code refusé au paiement.
