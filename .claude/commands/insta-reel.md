# Reel Instagram

1. Lire `docs/instagram/REGLES-INSTAGRAM.md` et la section « RECETTE VIDÉO PUB » de `CLAUDE.md` (style, outils, règles).
2. Numéro : continuer la numérotation de `docs/videos/REGISTRE-VIDEOS.md` (dernière vidéo + 1).
3. Base : un script existant de `tools/video/` (les effets de `noel_deco_verres_41.py` plaisent au gérant ; le style
   « magazine » `collage_52.py` aussi). Changer de style d'une vidéo à l'autre, et changer les produits (relire le registre).
   Sans thème donné = tous les univers. Version HyperFrames possible (`tools/video/hyperframes-noel/README.md`).
4. Photos : planche contact regardée en grand, uniquement gravées. Pas de prix, pas de stock.
5. Sortie 1080×1920 + version légère 720×1280 (crf 26, `-movflags +faststart`) dans `docs/videos/`, regarder 3 images clés
   avant d'envoyer, SendUserFile, légende au format fixe (`insta-legende`), ligne au registre le jour même.
