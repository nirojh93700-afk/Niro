# Légende Instagram

1. Lire `docs/instagram/REGLES-INSTAGRAM.md`.
2. Vérifier le produit à la source (`src/lib/products.js`, fiche en ligne) : ce qui se grave vraiment, les couleurs, les options.
   Jamais de prix sauf si le gérant le demande (alors `node tools/prix-fiche.mjs <slug>` juste avant).
3. Format FIXE (le même que les vidéos) :
   ```
   **<N° si vidéo> — <Thème>** (Produit 1, Produit 2…)
   > <accroche de 1 ligne avec un emoji>
   > <1 à 2 phrases : pour qui, ce qu'on grave, l'émotion>
   > 👉 Lien en bio · nivcreation.fr

   #nivcreation #cadeaupersonnalise #<produit> #<occasion> #ideecadeau
   ```
4. Proposer 2 accroches au choix. Pas de nombre de produits, pas de stock, pas de « fait main » sur bijou / verre / cristal.
5. Ajouter dans `docs/instagram/journal.md` : date, produit(s), légende retenue (pour ne pas se répéter).
